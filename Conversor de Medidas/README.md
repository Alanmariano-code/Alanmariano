# Metric Lab — Smart Unit Converter

Conversor responsivo de medidas de comprimento, desenvolvido com HTML5, CSS3 e JavaScript puro.

## Como executar

Abra `index.html` em um navegador moderno. Não é necessário instalar dependências nem iniciar um servidor.

## Recursos

- Conversão de metros para milímetros, centímetros, decímetros, decâmetros, hectômetros e quilômetros.
- Validação de campos vazios, números inválidos e valores negativos.
- Resultado formatado em português brasileiro, com até 10 casas decimais.
- Animação de processamento, feedback visual e mensagens de validação.
- Histórico das cinco conversões mais recentes, mantido durante a sessão.
- Cópia do resultado para a área de transferência e botão para limpar o conversor.
- Layout responsivo com suporte a preferência por movimento reduzido.

## Fórmulas

| Unidade | Conversão a partir de metros |
| --- | --- |
| mm | metros × 1000 |
| cm | metros × 100 |
| dm | metros × 10 |
| dam | metros ÷ 10 |
| hm | metros ÷ 100 |
| km | metros ÷ 1000 |
